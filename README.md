## Overview

This project focuses on analyzing customer data for a cafe business, with insights derived from various metrics and KPIs. It includes interactive charts, key performance indicators, and detailed demographics analysis.

## Features
- Customer demographics visualization
- Membership analysis by year and month
- Offer effectiveness tracking
- Time-based event distribution and analysis
- Visual insights on offer types, channels, and events

## Installation

### Prerequisites

- Python 3.7+
- Streamlit
- pandas
- seaborn
- matplotlib
- requests
- streamlit-lottie

### Steps

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/maven-cafe-dashboard.git
    cd maven-cafe-dashboard
    ```

2. Install the required packages:
    ```bash
    pip install -r requirements.txt
    ```

3. Run the Streamlit app:
    ```bash
    streamlit run app.py
    ```
